# Language Translator

### Overview

Language Translator is web-app that translate text into any language just like Google translator. This web-app build using Streamlit which is an open-source Python library for creating web applications.

deep-translator is a powerful Python library that provides a single, clean interface to translate text using various popular translation engines like Google Translate, DeepL, Microsoft Translator, and LibreTranslate.

### Tech Stack

* Python
* Streamlit
* Google Translate

### Environment (IDE)

1. VS Code
